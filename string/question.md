**Title:** Check if two string arrays are equivalent
**Description:** Given two string arrays `word1` abd `word2`. Return `true` if the two arrays represent the same string, and `false` otherwise.
A string is represented by an array if the array elements concatenated in order forms the string.

**Example 1:**
**Input:** `word1 = ["ab", "c"], word2 = ["a", "bc"]`
**Output:** `True`

**Example 2:**
**Input:** `word1 = ["ab", "c"], word2 = ["a", "bc", "d"]`
**Output:** `False`
